# Business Operator — Demo

A polished sales/demo build of Business Operator.

## What it demonstrates
- Business records checked automatically
- Payment shortfall detection
- Conflicting invoice detection
- Confidence scores
- Priority attention queue
- Explanations for why an issue was flagged
- Recommended next actions

This demo uses fictional sample data only.

## Run locally

```bash
python demo_server.py
```

Then open `http://127.0.0.1:8787`.

## Important
This is a demonstration build, not production financial software. Do not enter bank credentials or real customer data.
